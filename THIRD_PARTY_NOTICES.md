# Sumber dan lisensi

- Laravel: framework dan application skeleton, lisensi MIT. Lihat lisensi paket di `vendor/laravel/framework/LICENSE.md` setelah `composer install`.
- Plus Jakarta Sans: Google Fonts, SIL Open Font License 1.1. Lisensi disertakan di `public/fonts/PlusJakartaSans-LICENSE.txt`. Sumber: https://github.com/google/fonts/tree/main/ofl/plusjakartasans
- DM Serif Display Italic: Google Fonts, SIL Open Font License 1.1. Lisensi disertakan di `public/fonts/DMSerifDisplay-LICENSE.txt`. Sumber: https://github.com/google/fonts/tree/main/ofl/dmserifdisplay
- `public/images/photography.jpg`: gambar demo `about-bg.jpg` dari Start Bootstrap Clean Blog. Sumber: https://github.com/StartBootstrap/startbootstrap-clean-blog/tree/master/dist/assets/img . Lisensi template MIT disertakan di `docs/licenses/startbootstrap-clean-blog.txt`.
- `public/images/aftermovie.jpg`: gambar demo `bg-masthead.jpg` dari Start Bootstrap Grayscale. Sumber: https://github.com/StartBootstrap/startbootstrap-grayscale/tree/master/dist/assets/img . Lisensi template MIT disertakan di `docs/licenses/startbootstrap-grayscale.txt`. Foto ini adalah ilustrasi konsep perjalanan, bukan dokumentasi Gunung Bromo atau karya pemilik portofolio.
- `graduation.svg`, `content.svg`, `development.svg`, favicon, dan ikon inline: ilustrasi yang dibuat untuk proyek ini. Nama brand Daily Brew dan Frame digunakan sebagai contoh konsep, bukan representasi klien nyata.

Ganti gambar demo dengan dokumentasi milik sendiri saat mempersonalisasi portofolio.
